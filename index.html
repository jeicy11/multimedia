1. Actividades A y B

A. Digitalización de Trámites Universitarios (UMSA)

Los estudiantes deberán seleccionar dos trámites universitarios (por ejemplo: inscripción de materias, emisión de certificados o solicitud de títulos) y desarrollar una propuesta de modernización digital considerando los siguientes componentes:

  • A.a) Modelado del Proceso: Elaborar un diagrama de flujo que represente el funcionamiento completo del trámite, identificando entradas, procesos, validaciones y resultados.
  • A.b) BPM: Implementar un sistema de almacenamiento basado en archivos JSON, evitando el uso de servidores de bases de datos tradicionales. La información deberá poder registrarse, consultarse y actualizarse dinámicamente.

A.a) Modelado del Proceso

1. Metodología utilizada - Modelado del Proceso

Para el desarrollo del proyecto se realizó el modelado de procesos utilizando diagramas de flujo BPM (Business Process Management), con el objetivo de representar gráficamente el funcionamiento completo de los trámites universitarios digitalizados dentro de la Carrera de Informática de la UMSA.

El sistema implementa dos workflows principales:

F1: Inscripción de Materias F2: Emisión de Certificados

Cada flujo fue estructurado identificando claramente:

  • Entradas del sistema.
  • Procesos administrativos.
  • Validaciones académicas.
  • Roles responsables.
  • Resultados finales.

Flujo F1 — Inscripción de Materias

El proceso inicia con la solicitud realizada por el estudiante. Posteriormente, Kardex verifica el requisito académico y valida la información correspondiente. Luego, Director 1 y Director 2 realizan las revisiones y aprobaciones necesarias. Finalmente, Kardex registra oficialmente la inscripción y el estudiante recibe el resultado final del trámite.

Estudiante → Kardex → Director 1 → Director 2 → Kardex → Estudiante

Flujo F2 — Emisión de Certificados

El estudiante solicita un certificado académico. Kardex verifica los datos del historial académico y posteriormente el trámite pasa por las etapas de revisión y aprobación de Director 1 y Director 2. Luego, Caja registra el pago correspondiente y finalmente Kardex genera el certificado digital para que el estudiante pueda descargarlo.

Estudiante → Kardex → Director 1 → Director 2 → Caja → Kardex → Estudiante

Diagrama de Flujo BPM

Los diagramas BPM permitieron representar de manera clara el recorrido completo de cada trámite, facilitando la automatización del workflow.

b) Filtro de suavizado

IMPLEMENTACIÓN DE UN FILTRO DE SUAVIZADO

Filtro promedio con ventana de 3x3 píxeles para reducir ruido. Desarrollado en Python + OpenCV + NumPy.

PythonOpenCVNumPy

Código del filtro

import cv2
import numpy as np
imagen = cv2.imread("imagen.jpg")
alto, ancho, canales = imagen.shape
resultado = np.zeros((alto, ancho, canales), dtype=np.uint8)
for i in range(1, alto-1):
  for j in range(1, ancho-1):
    ventana = imagen[i-1:i+2, j-1:j+2]
    resultado[i, j] = np.mean(ventana, axis=(0,1))
cv2.imwrite("resultado.jpg", resultado)

c) Cover La Vaca Lola

COVER LA VACA LOLA - PRODUCCIÓN MULTIMEDIA

Producción multimedia: extracción de frames, ordenamiento, reconstrucción de video y sincronización con audio usando FFmpeg.

PythonOpenCVFFmpegGoogle ColabGoogle Drive

Estructura del módulo

vaca/ → baile.mp4 | vacalola.mp3 | frames/ | video.mp4 | videofinal.mp4

Pasos en Google Colab

  1. Montar Drive: drive.mount('/content/drive')
  2. Extraer frames con OpenCV
  3. Ordenar imágenes secuencialmente
  4. Reconstruir video con cv2.VideoWriter
  5. Sincronizar: ffmpeg -i video.mp4 -i vacalola.mp3 -c:v copy -c:a copy videofinal.mp4
